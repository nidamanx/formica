# Privacy

Formica does not collect, store or transmit any personal data outside your phone.

- The app has no internet permission, so it cannot send anything anywhere.
- It contains no ads, analytics, crash reporting or tracking libraries; it uses only
  open-source libraries (AndroidX, Kotlin).
- It has no access to location, contacts, camera, microphone, phone, messages or any
  other personal data.
- The data you enter (products, quantities, expiry dates, shopping list, notes, prices)
  and the name you give the phone are stored only on your device.
- To protect your privacy, this data is not included in Android backups nor copied to a
  new phone.
- Data leaves the phone only when you export it. The exported file is a plain JSON
  file, not encrypted: whoever receives it can read its content, including the phone's
  name. Send it only to people you choose.
- Before every import Formica keeps a copy of the data on the device (the last 5
  copies), so that the import can be undone. These copies never leave the phone.
- Uninstalling the app deletes all its data and copies.
